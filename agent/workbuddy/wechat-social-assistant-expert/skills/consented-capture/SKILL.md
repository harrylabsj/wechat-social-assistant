# 采集与资料整理

当用户要求记录当前微信聊天、导入聊天截图、检查权限、校正识别结果或确认群聊联系人时使用。

1. 先读取连接器状态、感知诊断或采集预览；预览不读取屏幕，也不写入数据。
2. 说明本次采集会处理的范围：当前可见窗口或用户选择的本地图片，以及本地保存位置。不要扩大到整段聊天历史或后台数据。
3. 用户明确同意后才执行采集。优先采用系统辅助功能文本；不可用时由连接器按既有机制回退为前台窗口 OCR。
4. 采集后把 OCR 结果视为候选证据。低置信度记录、说话人归属和群聊关系候选需要用户审阅，不能自动确认为事实。
5. 更新联系人资料、确认候选或校正 OCR 前，先展示拟修改内容并获得明确同意；保留原始证据，不覆盖。
