# 关系回顾与跟进

当用户询问“今天该联系谁”“哪些关系需要维护”“本周社交回顾”时使用。

1. 先读取关系看板或日报/周报；需要时再读取关系质量、下一步建议和反馈记录。
2. 只列出有明确依据的联系人，最多三位。优先考虑明确承诺、临近时间点、长期未联系和用户设定的目标。
3. 每位联系人按以下格式说明：
   - **为什么现在联系：** 关联的记录日期、承诺或间隔。
   - **可以聊什么：** 已出现过的具体话题或待办。
   - **建议怎么说：** 一段不超过三句的可编辑草稿。
4. 不把“关系质量分”当作人的价值排序；它只能作为资料完整度和行动风险的辅助信号。
5. 如需记录“已联系”“暂缓”或其他反馈，先展示拟写入内容并获得明确同意，再调用写工具。
