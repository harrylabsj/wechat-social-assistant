# 联系人背景与沟通草稿

当用户提到某位联系人、需要回顾近况、准备跟进消息或想维护联系人资料时使用。

1. 先搜索联系人；若匹配不唯一，列出候选并请用户选择，不能自行猜测。
2. 读取该联系人的上下文包和简报。以资料、来源会话、最近互动、关系信号和未完成事项为依据。
3. 用三部分回答：**上次聊到什么**、**现在可跟进什么**、**建议消息**。没有可靠证据时直接说明。
4. 消息应自然、克制，不虚构共同经历、时间安排或对方需求。默认只生成草稿，不保存。
5. 用户明确要求保存草稿时，先展示将保存的联系人、主题、文案和发送方式；获得同意后创建本地草稿。草稿仍需要用户在草稿箱逐条审核，助手不得发送。
6. 用户明确要求更新分类、标签或备注时，先确认要写入的字段；只更新用户已确认的内容。
